# project path

&nbsp;&nbsp;&nbsp;&nbsp;`$ project path`

Show the path to the project folder


## Examples
```
project path

project path set ~/Projects

project path config
```


## Subcommands
- [`config`](project-path-config.md) - Show the path to the project folder
- [`set`](project-path-set.md) - Set the path to the project folder
