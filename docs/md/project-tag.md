# project tag

&nbsp;&nbsp;&nbsp;&nbsp;`$ project tag <project> <tags> [flags]`

Manage tags on a project

## Options


 `-u`,  `--untag`

&nbsp;&nbsp;&nbsp;&nbsp;Untag one or multiple tags from a project


## Examples
```
project tag snake-game go,web

project tag snake-game

project tag snake-game rust -u
```
