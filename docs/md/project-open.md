# project open

&nbsp;&nbsp;&nbsp;&nbsp;`$ project open <project> [flags]`

Open a project

## Options


 `-a`,  `--app`

&nbsp;&nbsp;&nbsp;&nbsp;--app &lt;platform/target&gt;


## Examples
```
project open snake-game --app finder

project open api-server -a terminal

project open notes -a editor
```
