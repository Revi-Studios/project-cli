# project open

&nbsp;&nbsp;&nbsp;&nbsp;`$ project open <project> [flags]`

Open a project

## Options


 `-t`,  `--target`

&nbsp;&nbsp;&nbsp;&nbsp;--target &lt;application&gt;


## Examples
```
project open snake-game --target finder

project open api-server -t terminal

project open notes -t editor
```
